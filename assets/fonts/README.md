# Roboto

Source: Google Fonts Roboto Classic release v3.016, downloaded 2026-11-16:
https://github.com/googlefonts/roboto-3-classic/releases/tag/v3.016
https://github.com/googlefonts/roboto-3-classic/releases/download/v3.016/Roboto_v3.016.zip

Regular (400), Medium (500), and Bold (700) are unmodified static TrueType
files from the release's `hinted/static/` directory. SemiBold (600) is a
static instance of `hinted/Roboto[ital,wdth,wght].ttf`, generated with fontTools
varLib.instancer at wght=600, wdth=100, ital=0, updateFontNames=True.
Redistributed under the SIL Open Font License; see LICENSE.

Roboto's default capital I is a plain vertical stem. Lyrics use Medium.
These files are used for measurement and PDF embedding. SVG output embeds the
faces it uses. Internal CSS family aliases distinguish the weights for the
PDF converter, whose font callback only exposes a regular/bold flag.
